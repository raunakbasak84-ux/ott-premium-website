# StreamPremium - OTT Streaming Platform Website

A modern, responsive website for a premium OTT (Over-The-Top) streaming service built with HTML, CSS, and vanilla JavaScript.

## Features

- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Modern UI**: Clean and modern user interface inspired by popular streaming platforms
- **Navigation Bar**: Fixed navigation with smooth scrolling and mobile hamburger menu
- **Hero Section**: Eye-catching hero banner with video background
- **Featured Content**: Grid-based content showcase with hover effects
- **Features Showcase**: Six key features displayed in an attractive grid
- **Pricing Plans**: Three tiered pricing options (Basic, Premium, Family)
- **Contact Section**: Contact form and business information
- **Footer**: Comprehensive footer with links and social media

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. No build process required - it's a static website

## File Structure

```
ott-premium-website/
├── index.html       # Main HTML file
├── styles.css       # Stylesheet
├── script.js        # JavaScript functionality
└── assets/          # Images and videos folder
    ├── hero-video.mp4
    ├── content1.jpg through content6.jpg
```

## Customization

### Change Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #e50914;
    --secondary-color: #221f1f;
    /* ... other variables */
}
```

### Add Your Content
- Replace placeholder images in the Featured Content section
- Update pricing and features
- Modify company information in the Contact section
- Update footer links

### Add Video Background
Replace `assets/hero-video.mp4` with your own video file
